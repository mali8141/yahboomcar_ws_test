# Helper Scripts

---

## `start_core_robot.sh`

Sources the ROS 2 workspaces, configures audio, starts the micro-ROS agent and start any custom sensor modules.

```sh
./start_core_robot.sh
```

Internally this script calls `build_workspaces.sh` to ensure the workspaces are built before starting the robot.

### Flags

| Flag | Description |
|------|-------------|
| `--build_default` | Clean and rebuild the base workspaces (`yahboomcar_ws` and `M3Pro_ws`) before starting. |
| `--sim` | Start the robot in simulation mode (no micro-ROS agent or sensor modules). |
| `--record` | Start the UMA-16 audio recorder in addition to the sensor suite. |

---

## `build_workspaces.sh`

Script to build the necessary ROS 2 workspaces.

```sh
./build_workspaces.sh
```

### Flags

| Flag | Description |
|------|-------------|
| `--build_default` | Clean and rebuild the base workspaces (`yahboomcar_ws` and `M3Pro_ws`) before starting. |
| `--sim` | Compile packages for use in simulation mode. |

## `visualize_heatmap.py`

Live matplotlib viewer for the `/beamforming_heatmap` topic published by `uma16_acoustic_overlay`, which has no GUI of its own.

```sh
./scripts/visualize_heatmap.py
```

---

## `view_audio_map.py`

Simple viewer for recordings generated by the `audio_map` package. It uses
`realworld_ws/data` by default, or accepts a recording directory as an
argument. Click a point in the map to open its spectrogram; a point can also
be selected by recording ID or filename.

```sh
python3 helper/view_audio_map.py                 # use realworld_ws/data
python3 helper/view_audio_map.py --point 12      # open recording ID 12
python3 helper/view_audio_map.py --point recording_0012_20260913T212900Z.wav
```

## Mapper Scripts

Three SLAM mapping scripts (`mapper_gmapping.sh`, `mapper_rtab_visual_only.sh`, `mapper_rtab_full_fusion.sh`) cover GMapping 2D, RTAB-Map visual-only, and RTAB-Map full sensor fusion respectively. All support `--sim` for use with the Gazebo digital twin.

See **[mappers.md](mappers.md)** for full documentation, parameter tables, and a side-by-side comparison.
